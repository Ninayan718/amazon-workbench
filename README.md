# 亚马逊工作台

选品 / Listing / 广告 / 利润 的统一工作台。

单文件网页、零依赖、离线可用。所有文件与计算都在浏览器本地完成，不上传服务器。

## 利润模块（已接入核算引擎）

在「利润」页选结算报表 CSV（Custom Unified Transaction）+ 采购成本 XLSX（sku / 成本 / 空运头程），填汇率，点「开始核算」即可在浏览器本地算出：

- 按天：订单数、销售额 USD、结算额、订单利润 CNY、全口径到手
- 按 MSKU：件数、结算、成本、利润、单件利润
- 数据质量：重复 SKU、缺成本 SKU、已排除的提现

口径与本地 Python 核算脚本一致：订单 13 项结算字段带符号求和，减采购与空运头程；提现不计入费用；广告/Vine/仓储等非订单费用单列。xlsx 用纯 JS 解压，不依赖浏览器原生 API，iOS 旧版与微信内置浏览器也能用。

结果只存本机 localStorage（key `amz_profit_v1`），换设备请用同期工具另行搬运。其余模块仍走本地脚本产出 result.json 后导入。
